# Aux Proton Drive Bridge

Неофициальный десктопный мост для Linux для Proton Drive с использованием официального CLI `proton-drive`.

> Not affiliated with, endorsed by, or sponsored by Proton AG.

## Статус

Версия **`0.3.0`** - Полнофункциональная синхронизация, очередь передачи, разрешение конфликтов и поддержка FUSE-монтирования.

Aux Proton Drive Bridge предоставляет пользователям Linux графический интерфейс для операций с Proton Drive через официальный CLI Proton.

## Ключевые возможности

- **База данных метаданных синхронизации** - SQLite-отслеживание локального и удалённого состояния каждого отслеживаемого файла
- **Живая очередь передачи** - Конкурентные передачи с приоритетом, паузой/возобновлением, отменой и повтором
- **Парсер прогресса** - Анализ вывода CLI proton-drive в реальном времени для отображения прогресса
- **Обнаружение и разрешение конфликтов** - Выявление конфликтов LOCAL_REMOTE_MODIFY, LOCAL_DELETE_REMOTE_MODIFY, TYPE_MISMATCH, HASH_MISMATCH
- **Двунаправленная синхронизация** - Отслеживание локальной файловой системы через fs.watch + удалённый опрос через CLI
- **Режимы синхронизации** - Консервативный (только загрузка, пропуск существующих), однонаправленная загрузка/скачивание, двунаправленная
- **Автообновление** - Проверка и скачивание обновлений через GitHub Releases
- **Подпись релизов** - Скрипты подписи GPG и signify/minisign
- **Интеграция с файловым менеджером** - Скрипты контекстного меню для Nautilus, Dolphin, Thunar
- **Опциональное FUSE-монтирование** - Монтирование Proton Drive как директории файловой системы
- **Интерфейс с вкладками** - Отдельные вкладки для файлов, панели синхронизации, конфликтов, очереди, FUSE и обновлений

## Быстрая установка

### AppImage
Загрузите и запустите:
```
Aux.Proton.Drive.Bridge-0.3.0-x86_64.AppImage
```

### Debian / Ubuntu / Mint / Pop!_OS
```
sudo apt install ./Aux.Proton.Drive.Bridge-0.3.0-amd64.deb
```

### Fedora / RHEL / openSUSE
```
sudo dnf install ./Aux.Proton.Drive.Bridge-0.3.0-x86_64.rpm
```

## Требования

- Linux x64
- CLI Proton Drive: `proton-drive`
- Учётная запись Proton
- Доступ к браузеру для входа в Proton
- Хранилище секретов Linux (KWallet, GNOME Keyring/libsecret или `pass`)
- FUSE: опционально, только для функции монтирования

## Безопасность

- Aux Proton Drive Bridge никогда не запрашивает ваш пароль Proton.
- Аутентификация делегируется официальному CLI/браузерному потоку Proton.
- Учётные данные и токены удаляются из логов и хранимых данных.

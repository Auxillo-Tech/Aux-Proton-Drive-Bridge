# Aux Proton Drive Bridge

**Настольный клиент Proton Drive, которого не хватает Linux.** Просматривайте, загружайте, скачивайте и синхронизируйте свой Proton Drive — с односторонней и двусторонней синхронизацией, выборочной синхронизацией, обработкой конфликтов, очередью передач и подписанными релизами. Построен на официальном CLI `proton-drive` от Proton: ваши учётные данные никогда не покидают инструменты Proton.

> Неофициальный проект сообщества. Не связан с Proton AG, не одобрен и не спонсируется ею.

![Файлы](docs/screenshots/files-tab.png)

## Зачем это нужно

Proton не выпускает настольный клиент Proton Drive для Linux. Официальный CLI делает основную работу, но живёт в терминале. Aux Proton Drive Bridge оборачивает этот CLI в полноценное настольное приложение — аутентификация и шифрование целиком остаются в клиенте Proton.

## Возможности

- **Просмотр и передача** — список `/my-files`, скачивание выбранного или всего, загрузка файлов и папок
- **Фоновая синхронизация** — четыре режима: консервативный (только загрузка, пропуск существующих), односторонняя загрузка, одностороннее скачивание, полная двусторонняя
- **Выборочная синхронизация** — шаблоны исключения действуют в обе стороны: исключённые элементы не загружаются и не скачиваются
- **Обнаружение и разбор конфликтов** — изменения с обеих сторон, удаление-против-изменения, конфликты типа и хеша с безопасными стратегиями; синхронизация никогда не распространяет удаления
- **Очередь передач** — параллельные передачи с приоритетами, паузой/возобновлением, отменой и постоянной историей
- **Профили одностороннего резервного копирования** — резервные копии папок по расписанию с консервативной семантикой
- **Интеграция с рабочим столом** — системный трей, контекстные меню файловых менеджеров (Nautilus, Dolphin, Thunar), метаданные AppStream для GNOME Software / KDE Discover
- **Подписанные релизы и встроенное обновление** — контрольные суммы SHA-256, подписанные закреплённым ключом Ed25519

## Установка

Последняя версия: **<https://github.com/Auxillo-Tech/Aux-Proton-Drive-Bridge/releases/latest>**

- **AppImage** для любого Linux x86_64 — сделать исполняемым и запустить
- **`.deb`** для Debian / Ubuntu / Mint / Pop!_OS — `sudo apt install ./<файл>.deb`
- **`.rpm`** для Fedora / RHEL / openSUSE — `sudo dnf install ./<файл>.rpm`
- **AUR-архив** для Arch (PKGBUILD в комплекте)

Проверка загрузки:

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```

`SHA256SUMS.txt.sig` — подпись Ed25519 файла `SHA256SUMS.txt` (отпечаток `2148f39cd1004977cfde1d0a4be7b4fa`, открытый ключ в `release-manifest.json`).

## Требования

- Linux x86_64
- Proton Drive CLI, доступный как `proton-drive`
- Учётная запись Proton и браузер для входа Proton
- Хранилище секретов, поддерживаемое CLI (KWallet, GNOME Keyring/libsecret или `pass`)

## Быстрый старт

1. Установите Proton Drive CLI и проверьте, что `proton-drive version` работает.
2. Запустите Aux Proton Drive Bridge и нажмите **Sign in** — вход завершается в браузере.
3. Нажмите **Refresh files**, выберите элементы, укажите локальную папку, скачивайте или загружайте.
4. Откройте вкладку **Sync**, чтобы запустить фоновую синхронизацию в нужном режиме.
5. Просматривайте отмеченное на вкладке **Conflicts**.

Безопасные значения по умолчанию: при скачивании папки объединяются, существующие файлы пропускаются; синхронизация никогда ничего не удаляет ни с одной стороны.

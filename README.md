# Aux Proton Bridge

Unofficial Linux desktop bridge for Proton Drive using Proton's official `proton-drive` CLI.

Status: early MVP in development.

## Scope

- Detect installed Proton Drive CLI
- Launch Proton browser login through the CLI
- List `/my-files`
- Download selected/all folders into a local folder
- Upload local files/folders into Proton Drive
- Keep Proton credentials in Proton CLI's configured OS secret store; this app does not ask for or store Proton passwords.
